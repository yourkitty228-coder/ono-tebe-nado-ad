# Оно тебе надо

Учебный проект первого спринта: страница аукциона вещей, в которые никто не верил.

## Как открыть

1. Скачайте проект и распакуйте архив.
2. Откройте папку `ono-tebe-nado` в VS Code.
3. Откройте `index.html` в браузере (или через расширение Live Server).

## Структура

- `index.html` — разметка страницы.
- `styles/global.css` — глобальные стили и сброс отступов.
- `styles/style.css` — стили блоков и адаптивная вёрстка.
- `fonts/` — локальные шрифты Raleway.
- `images/` — изображения и логотипы.

Проект выполнен на HTML и CSS, без сборщика и внешних библиотек. Основной макет рассчитан на ширину 1100 px. На узких экранах контент перестраивается.
